# SauceDemo - Locator Identification

**Website:** https://www.saucedemo.com/

## 1. Login Page Locators

| Element | By.id | By.cssSelector | By.xpath |
|---|---|---|---|
| Username Input | `By.id("user-name")` | `input#user-name` | `//input[@id='user-name']` |
| Password Input | `By.id("password")` | `input#password` | `//input[@id='password']` |
| Login Button | `By.id("login-button")` | `input#login-button` | `//input[@id='login-button']` |
| Error Message | `no id attribute` | `input[data-test='error']` | `//input[@data-test='error']` |
