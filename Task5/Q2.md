# Q2 — CSS Selectors (The Internet: Tables)

Website: https://the-internet.herokuapp.com/tables

## Goal
Write CSS selectors for:
1. The 3rd column header
2. All rows in `tbody`
3. The cell containing `Smith`
4. All even rows


## 1. Target the 3rd column header

```html
<th class="header">
    <span>Email</span>
</th>
```

- `th` is a table header cell.
- `class="header"` is a class shared by the table headers, so it does not uniquely identify Email.
- Email is the 3rd header cell in the table's header row.
- `:nth-child(3)` selects the 3rd child element.

### CSS selector

```css
#table1 thead th:nth-child(3)
```


## 2. Select all rows in `tbody`

### CSS selector

```css
#table1 tbody tr
```
Selector breakdown:
- `#table1` — the table
- `tbody` — the body section
- `tr` — each row

## 3. Find the cell containing `Smith`


### CSS selector for first-column cells

```css
#table1 tbody td:nth-child(1)
```
### Verify in Console
```javascript
$$('#table1 tbody td:nth-child(1)')
  .filter(cell => cell.textContent.trim() === 'Smith')
```

## 4. Select all even rows

### CSS selector

```css
#table1 tbody tr:nth-child(even)
```

### Verify in Console

```javascript
$$('#table1 tbody tr:nth-child(even)')
```

## Summary

| Requirement | CSS selector | Console verification |
|---|---|---|
| 3rd column header | `#table1 thead th:nth-child(3)` | `$('#table1 thead th:nth-child(3)')` |
| All `tbody` rows | `#table1 tbody tr` | `$$('#table1 tbody tr')` |
| First-column cells (then filter for Smith) | `#table1 tbody td:nth-child(1)` | `$$('#table1 tbody td:nth-child(1)').filter(cell => cell.textContent.trim() === 'Smith')` |
| All even rows | `#table1 tbody tr:nth-child(even)` | `$$('#table1 tbody tr:nth-child(even)')` |
